# Window encounter prototype

Continue using Assets/Scenes/BedroomPrototype_PlayerFigure.unity. No new scene, player, camera or night manager is created.

Controls: F toggles flashlight; mouse aims; E gets out of bed after a window retreat, closes the window when looking at the close handle, and returns to bed when looking at the bed. Space remains blanket and R remains breath. F5 opens the window development panel (Editor/development builds only); F3/F4 remain existing threat debug panels. No flashlight F binding existed in the input asset before setup.

This Editor-only shortcut completes remaining morning replies using existing UI callbacks and enters bed through the normal transition. It respects current encounters; use F5 Force only when no threat owns the director. F5 also offers force retreat/open/reset closed.

WindowMonsterEncounter: Dormant -> Knocking -> Opening -> HeadEmerging -> AttackWarning -> Retreat or Attack. HumanM_Model is used as an independent visual with a project-owned upper-body mesh derived from the imported mesh, own URP material, idle controller and visual prefab. Imported files are not changed. Root motion is off. Upper-chest lean and head turn run after the Animator. No authored window/attack/locomotion clip is assumed.

BedroomWindowPanel preserves the original Daylight pane and crossbars under WindowPanelHinge, rotating outward by -95 degrees. The original sill and new edge frame stay fixed. Window closing handle is a stationary reachable operating lever; the moving latch rattles during knocking. Closing uses a one-second animation. Closing is refused while the monster occupies the opening. Head and face collider enter through the opening; no navigation mesh is used.

NightFlashlightController uses an independent Input System F action and a URP spot light attached to the original camera. Initial range8m, intensity2.2, spot38 degrees, face tolerance7 degrees. Detection requires an active light, nonempty charge when battery enabled, range/angle and a ray whose first solid obstruction is not a wall, furniture or glass before the face trigger. The player's own hierarchy is skipped. Continuous face illumination accumulates only during AttackWarning and resets to zero when aim is lost. Default required exposure0.8s, reaction2s. A blanket blocks emission. A mere toggle or light aimed elsewhere cannot counter.

Battery: maximum100, drain8 units/sec, recovery4 units/sec while off; exhaustion switches off and needs a deliberate retoggle. All values and battery enable are editable. Battery meter is confined to F5 debugging; the existing small reticle is available at night for aiming.

Open-window danger: window stays open after retreat. OpenSeconds produces relative weights1.5 below15s,2 below30s,3 maximum thereafter; closed weight1. Thresholds, multipliers and caps are in per-night config. BedroomEncounterDirector now queues automatic requests only once their independent cooldowns expire. It performs a weighted selection every configurable0.5s among eligible due requests; no per-frame probability rolls. Manual force uses the existing exclusive lease, not a probability roll. Higher window weight changes relative selection only when there are competing due threats; it does not bypass cooldowns. Warning duration reduces by up to25% at maximum danger, with explicit safe minimums. Closing removes pending window requests, resets danger and enforces a safe closed cooldown.

WindowNightExcursion uses BedroomPhaseController.NightStanding while the phase remains NightGameplay. Get-up and return use a short fade, the same capsule, movement script and camera. The original morning return position is retained independently. Standing night speed is limited to1.35m/s with sprint capped to that speed. Night look extends to180 degrees so the window behind the bed can be aimed at. Morning laptop/Truth/light-switch interactions stay disabled. The path uses existing room/furniture colliders; no second player or alternate physics implementation is introduced.

Scheduling: get-up, return and mandatory closing each hold an exclusive director lease, so attacks cannot begin inside those transitions. Under-bed and door warning stages can advance while standing. The director gives a configurable return-to-bed grace before a bed-only counter becomes mandatory. All defenses are unavailable while standing. Door and under-bed warnings remain possible while standing; the player must return to bed to defend. Window attacks are deferred until the player is back in bed. The night clock runs throughout the trip; returning never restarts it. Night loss/victory cancels threats, closes the window, turns off the flashlight and restores a consistent bed posture for retry.
